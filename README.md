# Громкость наушников

Мини-утилита для строки меню macOS: отдельная громкость для каждого устройства вывода и общий выход, который отправляет звук сразу на несколько Bluetooth-гарнитур. Удобно смотреть фильм вдвоём, каждый в своих наушниках.

## Возможности

- **Громкость по устройствам.** У каждой гарнитуры и у динамиков свой слайдер и кнопка выключения звука.
- **Куда идёт звук.** Быстро переключить вывод: общий выход, одни наушники или динамики.
- **«Обе гарнитуры».** Одной кнопкой собирает общий выход (Multi-Output) из всех подключённых Bluetooth-гарнитур.
- **Синхронизация.** Эталонные часы берутся с динамиков мака (стабильный кварц), гарнитуры подстраиваются под них с максимальным качеством компенсации дрейфа. Сами динамики при этом молчат.
  - «Без пролагов»: буфер 1024 кадра вместо 512. Меньше прерываний, задержка больше примерно на 12 мс.
  - «Задержать…»: от +10 до +200 мс для конкретной гарнитуры, если одна звучит раньше другой.
- **Запуск при входе** включается прямо из меню.

## Установка

Нужна macOS 13 или новее, Apple Silicon или Intel.

```bash
curl -fsSL https://raw.githubusercontent.com/Elintirs/headphones-mixer/main/install.sh | zsh
```

Скрипт скачивает последний релиз, кладёт приложение в `~/Applications` и запускает его. В строке меню появится иконка наушников.

Можно поставить и вручную: скачать `HeadphonesMixer.zip` со страницы [Releases](https://github.com/Elintirs/headphones-mixer/releases), распаковать и перенести приложение в «Программы». Приложение не нотаризовано, поэтому при первом запуске нажмите правой кнопкой → «Открыть» или выполните:

```bash
xattr -dr com.apple.quarantine ~/Applications/Громкость\ наушников.app
```

### Сборка из исходников

Нужны Xcode или Command Line Tools (`xcode-select --install`).

```bash
git clone https://github.com/Elintirs/headphones-mixer.git
cd headphones-mixer
./build.sh --install
```

## Удаление

```bash
curl -fsSL https://raw.githubusercontent.com/Elintirs/headphones-mixer/main/uninstall.sh | zsh
```

Удаляет приложение, его настройки и общий выход «Обе гарнитуры».

## Что важно знать

- **Громкость с клавиатуры не работает на общем выходе.** У Multi-Output в macOS нет общего регулятора, поэтому громкость меняется слайдерами утилиты.
- **Отставание от видео.** Общий выход сообщает плееру задержку Bluetooth (около 160 мс), и большинство плееров её учитывают. Если наушники реально запаздывают сильнее, поправьте сдвиг звука в плеере (IINA, VLC) или включите игровой режим наушников.
- **Пролаги.** Bluetooth и Wi-Fi 2,4 ГГц делят один радиомодуль. Два потока на гарнитуры плюс Wi-Fi 2,4 ГГц легко дают прерывания, поэтому лучше подключаться к сети на 5 ГГц.
- Чтобы часы совпадали, утилита переводит динамики мака на 44,1 кГц, родную частоту Bluetooth A2DP.
